# SERNEM Toolbox Quality Gate — 13 November 2026

## Scope and outcome

- Baseline: 70 unique Toolbox topics in `app/lib/toolbox/toolbox-data.ts`, each with Turkish and English copy.
- Structural validation of existing catalogue found no missing required topic sections, duplicate slugs, duplicate titles, or absent bilingual fields.
- Source-tree asset verification: all 70 static master topics have 2 standard and 2 branded-base locale PDFs (140 + 140 = 280 files). This check proves presence, **not successful rendering, correct pagination, or readability**.
- QA corrections: existing base entries now use the same category classifier as auto entries; the generic refinery photograph in visual PDF is labelled **illustrative**, not a site-specific photograph; four one-word hazard descriptions were clarified.
- Added an automated content-quality gate to the prebuild and Toolbox CI workflow. The gate checks bilingual content completeness, descriptions, duplicated content/slug/title, minimum discussion counts, PDF master paths, download routing and labels. Automated QA cannot approve legal or technical correctness.
- Two unique specialist topics were prepared in TR/EN: `manual-torque-wrench-safety` and `hot-work-near-fuel-systems`. Catalogue source is now 72 distinct topics / 144 localized versions on **this branch only**.
- The two new topics are intentionally not added to the legacy static PDF master list. They use the existing authenticated dynamic PDF route; this needs an actual Preview generation and render test in both locales before publishing.

## Release gates — do NOT skip

1. `npm run qa:toolbox-content` and `npm run qa:toolbox-pdfs` in CI; TypeScript/build and Vercel Preview must pass.
2. Generate and visually inspect both new TR/EN PDFs, plus baseline representative PDFs on desktop/mobile and A4 print. Check page count, line wrapping, headings, date/owner fields, and 12-row attendance signatures.
3. Confirm unauthenticated HTML preview; unauthenticated PDF redirects to login; authenticated Free download; Premium output permissions; no broken links or entitlement regression.
4. Human HSE/technical review of high-consequence instructions, especially approved torque/lubrication method, loss-of-resistance pinch points, live diesel-system isolation, hot-work permits, fire-protection impairment and emergency planning. Local rules, permits and engineering designs take precedence.
5. Confirm production site still has 70 until merge and deploy; only then measure 72. No claims of SEO or Premium conversion improvement without analytics.

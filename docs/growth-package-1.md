# SERNEM Growth Package 1

Goal: turn search visitors into repeat product users by connecting SERNEM's existing HSE modules into one workflow.

Planned scope:
- topic-aware cross-links between posters, toolbox talks, inspections, guides and risk assessments
- a Safety Pack entry point that routes users from one activity to the relevant existing SERNEM tools
- conversion-oriented CTAs without hiding useful free content
- analytics events for cross-module navigation and Safety Pack starts
- internal-link/SEO improvements around high-intent HSE topics

PDF export-engine work remains in the separate pending PDF package so the growth release stays focused and reversible.
